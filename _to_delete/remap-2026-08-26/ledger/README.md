# ledger — the record of accountability

*This project has no institution behind it, no funding and no client. The only credential it can
offer is a complete, append-only record of its own mistakes, and this is it. Split from a single
1,128-line file on 21 August 2026; the content is unchanged.*

- **[The errata register](./errata.md)** — every published claim that turned out to be wrong, each
  with what was said, what was true, how it was caught, and the fix. Nothing is deleted; corrections
  are appended and the superseded wording is preserved beside them.
- **[The changelog](./changelog.md)** — what changed in the statutory text and when, with the
  sha256 checksums that make each tagged edition reproducible.
- **[The diary](./diary.md)** — the working account, day by day: what was read, what was found, what
  was refused, and what is owed next.

*A pointer file remains at [`../LEDGER.md`](../LEDGER.md) so that existing links, and the anchors
`#part-i`, `#part-ii` and `#part-iii` cited across the repository and in published material,
continue to land.*
